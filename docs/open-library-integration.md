# تكامل الكتب مع Open Library

يستخدم Blinkr واجهة البحث العامة في Open Library عند إدخال عبارة بحث، لذلك لا يحتاج التطبيق إلى تنزيل نسخة كاملة من قاعدة الكتب أو وضع مفتاح API في الهاتف. يوثّق Open Library طلب البحث عبر `/search.json`، مع إمكانية تحديد الحقول والصفحة وعدد النتائج [1].

يعالج الخادم نتيجة البحث إلى بطاقة موحدة تشمل معرّف العمل `OL…W`، والعنوان، وأسماء المؤلفين، وسنة النشر، وISBN، وعدد الصفحات الوسطي والتقييم عند توفرها. ويحوّل `cover_i` إلى صورة غلاف باستخدام واجهة الأغلفة الرسمية، مع اختيار حجم متوسط وإخفاء صورة placeholder الافتراضية عند عدم توفر غلاف [2].

عند فتح الكتاب، يطلب التطبيق بيانات العمل الفردية لإظهار الوصف والموضوعات وتاريخ النشر. تبقى أغلفة الكتب مستضافة لدى Open Library؛ التطبيق لا يخزن صور الأغلفة في قاعدة بيانات Blinkr. يستخدم الخادم مهلة قصيرة وحدًا أقصى للنتائج في كل صفحة، ويرسل User-Agent يعرّف التطبيق. ولا تُنفّذ طلبات bulk أو تنزيل للـdump.

لتقليل الطلبات المتكررة، يحتفظ الخادم بنتائج البحث في ذاكرته لمدة خمس دقائق وتفاصيل الكتاب لمدة ست ساعات، وبحد أقصى 200 مدخل. هذه ذاكرة مؤقتة داخل عملية Render فقط؛ لا تنشئ جداول أو صفوفًا في Aiven، وتُمسح عند إعادة تشغيل الخادم. تُحفظ في قاعدة البيانات فقط بيانات Blinkr التي يضيفها المستخدم بنفسه مثل مراجعات الكتب وحالاتها، لا سجل Open Library أو صور الأغلفة.

البيانات النصية والأغلفة مصدرها Open Library؛ ينبغي مراجعة شروط استخدام البيانات والصور عند تغيير طريقة عرضها أو إعادة توزيعها [3] [4].
